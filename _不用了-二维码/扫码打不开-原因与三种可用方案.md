# 扫码打不开：原因已查明，附三种可用方案

> 排查时间：2026-10-25　｜　结论：不是二维码做错了，是"用什么扫"和"站点资源加载方式"两个问题叠加。

---

## 一、查明的原因（两条，都有实测依据）

### 原因 1：微信内置浏览器被托管平台拦截（返回 403）

我用不同客户端的 UA 实测了同一个链接：

| 扫码方式 | 结果 | 说明 |
|---|---|---|
| iPhone 相机（走 Safari） | ✅ 200 | 正常打开 |
| 安卓相机 / 浏览器（走 Chrome） | ✅ 200 | 正常打开 |
| 电脑浏览器 | ✅ 200 | 正常打开 |
| **微信"扫一扫"** | ❌ **403** | **被拦截，打不开** |

`Server: CloudStudio Gateway` 这一层对微信内置浏览器的 UA 直接返回 403。**这一层我改不了**，属于托管平台的策略。

**如果你刚才是用微信扫的，这就是打不开的直接原因。**

### 原因 2：页面依赖外部资源，而资源请求被单独拦截（已修复）

原来的站点是多文件结构：`index.html` + `styles.css` + `app.js` + 一个 jsdelivr CDN 上的 `html2canvas`。

实测发现一个要命的现象：

```
GET /index.html?sharecode=xxx   → 200   （页面本体放行）
GET /app.js                     → 403   （脚本被拦）
GET /styles.css                 → 403   （样式被拦）
```

也就是说：**页面能打开，但样式和脚本全被拦掉**。浏览器里看到的就是——大白字、没有排版、按钮点了没反应。这在外行看来就是"打不开"。

（`app.js` 带上 `?sharecode=` 参数时是 200，说明平台是按"每次请求是否带凭证"来鉴权的，而相对路径的子资源请求天然不带这个参数。）

另外 `html2canvas` 来自 `cdn.jsdelivr.net`，**国内根本连不上**（实测返回 000），报告导出图片这个功能在国内必然失败。

---

## 二、已经做的修复：合并成单文件

把 `styles.css`、`app.js`、`html2canvas` 全部内联进 `index.html`，做成了一个 **256 KB 的自包含 HTML**。

效果：

- **整站只剩 1 个请求**（`index.html?sharecode=xxx`），不再有子资源被拦的问题
- 不再依赖任何 CDN，国内、断网都能跑
- 顺手给 `localStorage` 加了异常保护——手机本地直接打开 html 文件时，部分浏览器会禁用 localStorage 并抛错，原代码会让"保存报告"崩掉，现在会自动退回内存存储

线上已重新发布并验证：返回 264254 字节，外部引用 0 处，标题、样式、交互全部正常。

## 三、三种可用方案（按可靠性排序）

### 方案 A（最稳）：手机本地文件，完全不用网络

文件：`大展红途-离线单文件.html`（256 KB）

1. 电脑微信「文件传输助手」把这个 html 发给自己
2. 手机微信里点开 → 右上角「…」→ **用其他应用打开** → 选 Safari / Chrome
   - iOS：先在「文件」里保存，再用 Safari 打开
   - 安卓：下载后用 Chrome 打开
3. 打开后建议「添加到主屏幕」，图标和 App 一样，点开即用

**优点**：会场没网、网络差、被墙，全都不影响。**路演现场演示就该用这个。**

### 方案 B：线上链接，但用相机扫、不要用微信扫

链接：`https://dazhan-hongtu.app.workbuddy.host/?sharecode=EL5LQFTLBD`

- iPhone：直接用**相机**对准二维码 → 顶部弹出横幅 → 点开（会走 Safari）
- 安卓：用**相机 / 系统扫码**，不要用微信
- 微信里粘贴这个链接也会 403，**只能"在浏览器中打开"**

### 方案 C：现场用你自己的手机演示

评委不需要扫码。**5 分钟路演，手机就在你手里**，你操作给他们看即可。二维码的价值是"让评委觉得这东西真的能用"，不是"必须让评委当场打开"。

## 四、给路演的建议（重要）

**不要设计"请评委扫码"这个环节。**

三个理由：

1. 评委大概率用微信扫，而微信扫出来是 403，你会在台上当场尴尬
2. 会场网络不可控，扫码等待时间不可控
3. 5 分钟很短，任何一次等待都是浪费

**正确做法**：PPT 最后一页放二维码 + 一行小字"扫码体验（请用手机相机扫描）"，作为「会后可自行体验」的入口，而不是现场互动环节。现场演示用你自己的手机（方案 A 的本地版）。
