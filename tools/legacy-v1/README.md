# legacy-v1 · v1 版本的出图工具

这里是 v1（黄洋界单点位版本）做 PPT 素材用的一次性脚本，产物已经归档，脚本本身不再维护。

**为什么单独放一个目录**：这些脚本在根目录时混在应用代码里看不出层级，移动到这里是为了让根目录只保留"要跑的东西"和"要读的东西"。

## 文件说明

| 文件 | 做什么 | 产出 |
|---|---|---|
| `_shot.js` | 截 v1 六个视图 | `_shots/`（已删除，产物在 `PPT素材/`） |
| `_shot_frame.js` | 给截图套手机外壳 | `PPT素材/手机框/` |
| `_shot_showcase.js` | 截 PPT 展示页（深/浅两版） | `_shots/` |
| `_shot_docfig.js` | 截文档配图 | `_shots/` |
| `_compose_hd.py` | 把手机框图合成整页高清图 | `PPT素材/01-产品界面总览-*.png` |

## 重跑前要注意

**这五个脚本里的仓库根目录是写死的**：

```js
const ROOT = "D:/大展红途";
```

所以移到这里不会失效——但也意味着**换机器或改目录名就跑不了**，需要先把 `ROOT` 改成新路径。

**它们依赖三个 HTML 模板，仍留在仓库根目录**（脚本用绝对路径加载，所以模板不能一起搬）：

- `showcase.html` —— v1 的 PPT 展示页
- `frame.html` —— 手机外壳模板
- `_docfig.html` —— 文档配图模板

搬走这三个模板会让对应脚本失效，要动的话记得同步改脚本里的 `file:///D:/大展红途/...`。

## 现在该用哪个

v2 的出图工具是 `tools/shoot_v2.js` 和 `tools/shoot_ppt_v2.js`，产物在 `v2/_shots/` 和 `v2/PPT素材/`；
