# 大展红途 · 运行方式说明

本项目有**两种运行方式**，看到的回答完全不同。分不清这一点，就会误以为"全部是预置答案"。

| | 方式 A：直接打开 / 静态服务 | 方式 B：`node server.js` + key |
|---|---|---|
| 怎么启动 | 双击 `index.html`，或 `python -m http.server` | 填好 `.env` 后 `node server.js` |
| 回答从哪来 | 前端 `FALLBACK` 里 8 组预置文本 | 服务端检索史料 → **真模型生成** |
| 能答多少问题 | 只有那 8 组，其余一律拒答 | 语料覆盖的 20 个主题，问法不限 |
| 界面提示 | 黄色 ● 离线讲解 · 预置史料 | 绿色 ● 在线模型 · 模型名 |

**方式 A 只是保命用的。** 它的存在意义是：万一现场断网、服务挂了，页面还能演示，不至于白屏。它不是这个产品的 AI 能力。

---

## 接真模型：三步

### 1. 建配置文件

把 `.env.example` 复制一份，改名为 `.env`（Windows 下注意别变成 `.env.txt`）。

### 2. 填 key

```ini
LLM_API_KEY=你的密钥
LLM_BASE_URL=https://api.deepseek.com/v1
LLM_MODEL=deepseek-chat
```

`LLM_BASE_URL` 和 `LLM_MODEL` 必须配套。三项都不填只有 key 也行——那就走 OpenAI 官方 + `gpt-4o-mini`。

**可用的 OpenAI 兼容接口**（任选其一，注册一般都有免费额度）：

| 平台 | BASE_URL | MODEL 示例 |
|---|---|---|
| DeepSeek | `https://api.deepseek.com/v1` | `deepseek-chat` |
| 智谱 GLM | `https://open.bigmodel.cn/api/paas/v4` | `glm-4-flash`（免费档） |
| 阿里通义 | `https://dashscope.aliyuncs.com/compatible-mode/v1` | `qwen-plus` |
| 第三方中转 | 由服务商提供，通常以 `/v1` 结尾 | 按其文档 |

> 凡自称 "OpenAI 兼容" 的接口，只要支持 `POST /chat/completions`，本项目都能用。

### 3. 启动

```bash
node server.js
```

看到 `模式   在线模型（真调用）` 就成功了。浏览器打开 `http://127.0.0.1:8123`，进「问 AI」页，右上角应显示绿色圆点和模型名。

## 为什么不直接让前端调模型

前端直连需要在 `app.js` 里写 key，任何人打开网页源码都能拿到，拿去刷你的额度。所以 key 必须留在服务端。

`api/chat.js` 和 `api/comment.js` 是 Vercel Serverless 函数格式，`server.js` 只是把它们在本机跑起来；同一份代码可以直接部署到 Vercel，不用改。

---

## 现场演示怎么选

**建议：带 key 真跑，同时准备方式 A 作为断网预案。**

理由：
- 界面那个绿点本身就是证据。评委看到"在线模型 · deepseek-chat"，比你说十句"我们接了大模型"都管用。
- 真模型的回答会针对问法组织语言，比 8 条固定文本自然得多。
- 万一会场网络不行，切到方式 A 也能撑完全程，只是回答范围变小。

**赛前务必演练一次断网切换**：关掉 server.js，刷新页面，确认界面变黄、仍能对话。

## 目录说明

```
index.html          页面结构（六个视图：首页/点位/对话/任务/报告/教师端）
app.js              前端逻辑：视图切换、任务、评分、离线兜底检索
styles.css          样式
server.js           本地服务：静态托管 + 把 api/ 下的函数跑起来 + /api/health
api/chat.js         服务端检索（史料锚定）+ 调用模型
api/comment.js      生成研学评语
data/corpus.json    已审核史料，检索的依据
data/tasks.json     任务数据
.env.example        配置模板（复制为 .env 使用）
_probe.js           检索验收脚本：node _probe.js，34 个用例
```

`.env` 和 `server.js` 已被服务端设为禁止下载，避免 key 泄露。
