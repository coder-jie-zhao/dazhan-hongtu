大展红途 · 功能改进说明（2026-11-16）

这一轮补齐的是模块之间的连接：原来「问 / 做 / 留」三块各自完整，但衔接是断的。
下面每一项都对应一个具体断点，并写明现场怎么用。

一、AI 回答可以朗读
对话页每条回答下有「朗读」按钮，顶部有自动朗读开关（默认关）。
用的是浏览器自带语音合成，本地运行、断网可用。
手机不支持时会藏起按钮，不承诺所有机型都能出声。
现场用法：点「朗读」让讲解开口说，不用自己念。

二、依据可以点开看原文
回答下方的出处不再是纯文字，而是一排可点的标签。
点一下弹出史料原文卡：原文 + 出处 + 年份 + 原网页链接。
卡片内容来自本地语料，断网也能看；外链只是补充。
现场用法：评委问「这答案哪来的」，直接点依据给他看原文。

三、研学报告可以打印成 PDF
报告页有「打印 / 存为 PDF」按钮，走浏览器打印，离线可用、字是矢量不糊。
报告底部加了带队教师签注栏：学校、教师签名、日期。
现场用法：学校归档要纸质件时，打印出来老师签字。

四、排序题答完给出时间轴
历史事件排序题答对后，下方出现一条横向时间轴，标出正确顺序。
答错时把放错位置的卡片标红，学生能看出错在哪。

五、拒答后推荐能答的问题
AI 拒答时，解释卡下方给出三个本点位有史料支撑的相邻问题，点一下直接问。
把「它不回答」变成「换个问法它就能答」。

六、现场模式
首页工具区和教师端都有「现场模式」开关，开了以后字变大、动画全停、背景轮播停止。
给带队老师在太阳底下用，省电省流量。状态存在本机，刷新后保持。

七、线路总报告
报告页有「线路总报告」入口，也是一个独立页面（#/summary）。
把三个点位合起来看：线路完成状态、四维能力平均分、合并后的提问时间线、各点位评语。
分数仍由固定规则算出，评语仍是模板拼接引用学生原话，全程不调用模型。
这是「一次研学」真正能归档的交付物，不再是三张碎片报告。

八、点位二维码与深链
三个点位各有独立二维码和 A4 点位牌，扫码直达对应点位页。
生成脚本：materials/_make_qr.py，用法：
  python _make_qr.py https://当天域名/?eo_token=xxx
注意：EdgeOne 默认域名直连会被拦，必须用当天「预览」生成的带 token 链接；
预览链接 3 小时过期，所以二维码要现场生成、当场用。
断网兜底时把参数换成本机 http://127.0.0.1:8130/ ，印出来给现场扫本机热点。

九、教师端可以改任务单
任务单生成器现在支持：改题干、删题、加自定义题、恢复默认、导出 txt。
改动只存在本机浏览器，不上传，老师出行前按需调整即可。

十、代码降 AI 化
这一轮新写的代码按人工风格整理：去掉带日期的横幅注释、绝对化承诺和解释性套话，
注释只保留「为什么这么做」，命名沿用项目原有的 ES5 风格。
原因是这个项目要拿去申请软著，鉴别材料里的源代码不宜带明显的机器生成痕迹。
