# 大展红途 · H5 截图与 PPT 用法

> 一句话：**双击 `index.html` 就能用，不用服务器、不用扫码、不用联网。**
> 截图已经出好了，都在 `PPT素材/` 里，直接拖进 PPT。

---

## 一、怎么打开这个 H5

双击 `D:\大展红途\index.html`

- 会自动弹一个填姓名的框（演示时填你自己的名字，之后不再问）
- 页面依次是：入口 → 点位详情 → 问 AI / 做任务 → 研学报告
- 教师端：浏览器地址后面加 `#/teacher`

**现场演示建议**：用 Chrome 打开，按 `F12` → 点左上角手机图标（Toggle device toolbar）→ 选 iPhone 14 Pro，就是手机样子了，鼠标点着讲。

## 三、PPT 里怎么排（建议）

按 10~12 页的体量，**图片用在第 4~7 页最合适**：

| PPT 页 | 放什么图 | 页面标题建议 |
|---|---|---|
| 第 4 页 · 产品形态 | `01-产品界面总览-浅色` | 一个 H5，走完"问—做—得" |
| 第 5 页 · 核心功能 | `04-AI对话`（手机框版）+ `07-研学报告`（手机框版）并排 | 答案有出处，报告有依据 |
| 第 6 页 · 现场任务 | `05-现场任务-首屏` 或 `06-现场任务-全程` | 把"逛一圈"变成"做一遍" |
| 第 7 页 · 教师端/数据 | `08-教师端` | 学生有收获，老师有数据 |

**排版小技巧**
- 手机框图高度控制在 11~13cm，两到三台并排刚好占满一页右侧
- 图片别拉伸变形，按住 Shift 等比缩放
- 浅色 PPT 用浅色总览图，深色 PPT 用深色版；单屏图本身就是浅底，通用

## 四、几个必须知道的细节

1. **报告页的分数是"演示态"的满配数据**（100 / 75 / 100、停留 32 分钟、3 次提问）。
   这是为了截图不出现"0 分空报告"。答辩时如果评委问，就说"这是演示账号的完整数据"。

2. **教师端标了"演示数据（示例）"**，图上也有这行小字。别在 PPT 里把它说成真实采集。

3. **对话页标注"史料依据 · 18 条已审核"**——这是真实的：回答确实从 18 条已审核史料里检索。截图没有伪造"在线模型"字样。

4. **不带参数打开就是正常使用流程**（填姓名 → 点位 → 问 → 做 → 报告），适合现场演示。
   截图用的 `?demo=1` 只影响截图，不影响正常使用。

## 五、想自己重截（可选）

```bash
# 单屏图（输出到 _shots/）
node _shot.js              # 全部
node _shot.js home chat    # 只截指定页

# 总览图（深浅两版，输出到 _shots/）
node _shot_showcase.js

# 手机框图（输出到 PPT素材/手机框/）
node _shot_frame.js
```

需要先装依赖（只装一次）：
```bash
npm install puppeteer-core
```

如果只是想微调文字/颜色，改 `index.html`、`styles.css`、`app.js` 后重跑上面命令即可。
