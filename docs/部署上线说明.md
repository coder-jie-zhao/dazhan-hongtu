# 把这个 Demo 变成网址

> 目标：别人点一个链接就能打开、能用，不用装任何东西。
> 前提：`dist.zip` 已经打好（`python tools/build_deploy.py` 生成，3.2MB）。

---

## 先说结论：选哪个

| 方案 | 国内访问 | 能跑 AI 真模型 | 难度 | 推荐场景 |
|---|---|---|---|---|
| **腾讯云 EdgeOne Pages** | 快（国内节点） | 能（云函数） | ★★☆ 上传/关联仓库 | **给别人看、路演扫码、带模型** |
| Vercel | 一般（常被墙） | 能（serverless 函数 `/api/chat` + `/api/health`） | ★★☆ `npx vercel` 或连 GitHub | 评委/老师能翻墙 |
| GitHub Pages | 慢/不稳 | 不能 | ★★☆ 配分支 | 和代码放一起存档 |

**建议：优先用 EdgeOne Pages（国内节点、不用备案）。要纯展示用 `dist.zip`（拖拽即可，AI 走本地检索）；要带真模型用 `dist-online.zip`（含云函数，AI 走 DeepSeek）。两个都是同一个网址体系，切换只差一个 zip 和三项环境变量。**

为什么纯静态就够：这个项目从设计上就支持「没有后端也能完整演示」——
AI 回答走 `js/core/net.js` 的本地兜底，用同一份检索算法 + 人工撰写的离线问答库。
**回答照样带史料出处，超纲问题照样拒答。** 已经实测验证过。

## 方案一：EdgeOne Pages（推荐，5 分钟）

### 步骤

1. **开通**
   打开 https://console.cloud.tencent.com/edgeone/pages
   用微信/QQ 登录（腾讯云账号），点「立即开通」。免费，不扣费。

2. **上传**
   点「新建项目」→ 选「直接上传」（有的版本叫「本地上传」）
   把 **`dist.zip`** 拖进去
   项目名填英文小写，比如 `dazhan-hongtu` —— 会出现在网址里

3. **部署**
   点「开始部署」，等 20–40 秒

4. **拿到网址**
   形如 `https://dazhan-hongtu.edgeone.app`
   打开就是你的网站，自动 HTTPS。

### 注意

- **不需要备案**。默认的 `*.edgeone.app` 子域名可以直接用。
  只有绑自己的域名（如 `hongtu.com`）且要国内加速时，才需要 ICP 备案（免费但审核 1–2 周）。
- 单个文件上限 25MB。`dist` 里最大的图片 1.8MB，没问题。
- 更新内容：控制台里找到项目 → 「更新部署」→ 重新拖 zip。

### 进阶：带真模型的版本（EdgeOne 云函数）

> 适用：希望网址上的 AI 也走真实 DeepSeek 模型（回答更接近讲解、能处理跨点位比较题）。
> 和纯静态版的区别：多了一个 `cloud-functions/api/chat.js`，AI 回答由模型生成，而不是本地史料直出。
> 实战建议：路演主路仍用笔记本双击 `v2/index.html`（最稳，断网也能演），这个网址版作为「给别人远程看」的增强版。

**产物**：`dist-online.zip`（由 `python tools/build_deploy_online.py` 生成，3.2MB）。
它 = 静态站点 + `cloud-functions/`（云函数）。注意静态根目录里**故意不含 `api/`**，
否则 `/api/chat` 会被当成静态文件返回源码、函数不会触发。

**部署（两种方式，任选）**

方式一 · 直接上传（最快，多数情况够用）
1. 在 EdgeOne Pages「新建项目」→「直接上传」，把 **`dist-online.zip`** 拖进去。
2. 部署完成后，在【项目设置 → 环境变量】里加三项：
   ```
   LLM_API_KEY      你的 DeepSeek key
   LLM_BASE_URL     https://api.deepseek.com/v1
   LLM_MODEL        deepseek-chat
   ```
3. 改完变量记得「重新部署」一次让变量生效。

方式二 · 关联 GitHub 仓库（函数绑定最稳，推荐用于正式上线）
1. Pages 新建项目时选「连接 Git 仓库」，选你的 `coder-jie-zhao/dazhan-hongtu`。
2. 构建命令填：`python tools/build_deploy_online.py`
   输出目录填：`dist-online`
   （仓库里已包含该构建脚本，且只用 Python 标准库，构建环境有 Python 即可；
    若想跳过构建，也可把本地已生成的 `dist-online/` 目录提交进仓库、构建命令留空，平台把它当成品部署。）
3. 在【项目设置 → 环境变量】里加上面三项。

**上线后验证（关键，避免现场翻车）**
- 浏览器打开 `https://你的站点.edgeone.app/api/chat`
  → 应返回一段 JSON（含 `"ok":true`、`"service":"dazhan-hongtu /api/chat"`）。
  这说明云函数已挂载成功。
- 如果返回的是「文件下载」或 404，说明函数没绑定上：改用方式二（关联仓库）重新部署即可。
- 用手机流量打开主站，问一个跨点位比较题（如「黄洋界保卫战和井冈山会师哪个先发生」），
  若 AI 能跨点位取材作答、且回答带史料出处，说明模型链路通了。

**安全提醒**
- DeepSeek key 写进 Pages 环境变量（服务端持有，不会出现在前端代码里），比放前端安全；
  但比赛结束后仍建议**重置/作废该 key**——仓库里、聊天记录里都已出现过明文。
- 没配 key 时云函数会自动降级为「服务端史料直出」（有出处、能拒答），不会白屏。

## 方案二：Vercel（能跑真模型）

这个方案的 AI 跑在 Vercel 的 serverless 函数里，走真实 DeepSeek 模型（回答更像讲解、能处理跨点位比较题），
而且**不用备案、不用自己买服务器**。代价是 Vercel 国内常被墙，适合「评委/老师能翻墙」的场景。

> 一句话原理：Vercel 的 Node 函数原生支持 `req.body`（自动解析 JSON）和 `res.status().json()`，
> 所以本项目 `v2/api/chat.js` 的业务逻辑**一行不改**就能当函数跑。
> 我们额外补了一个 `/api/health` 函数——**这个必须有**：前端 `net.js` 会先打 `/api/health` 探测，
> 只有返回 `online` 才会调 `/api/chat`；没有它，前端会误判离线、永远走本地检索，真模型链路就断了。

### 产物

`dist-vercel/`（由 `python tools/build_deploy_vercel.py` 生成，3.5MB）=
静态站点（`index.html` + `js/` + `data/` + `styles/` + `assets/`）
\+ 函数目录 `api/`（`chat.js` 入口、`health.js` 健康检查、`_handler.js` 业务实现）。
注意静态根目录里**故意不含 `api/` 同名静态文件**——`api/` 是函数目录，Vercel 会接管。

### 部署方式一 · 本地命令（最简单，推荐先试这个）

不需要推 GitHub，本机一条命令就能上线：

```bash
# 没装过 vercel 也能用 npx 直接跑（首次会让你用 GitHub 登录授权）
npx vercel dist-vercel
# 想直接上生产域名（而非 xxx.vercel.app 预览），加 --prod
npx vercel deploy dist-vercel --prod
```

部署完会返回一个网址，形如 `https://dazhan-hongtu-xxx.vercel.app`。

### 部署方式二 · 连 GitHub 自动部署

1. 打开 https://vercel.com ，用 **GitHub 账号**登录（你的 `coder-jie-zhao`）
2. **Add New → Project** → 选 `dazhan-hongtu` 仓库 → **Import**
3. **Root Directory** 填 `dist-vercel`
   （`dist-vercel/` 是已经打好的成品，函数 `/api/chat`、`/api/health` 都在里面；
    构建命令留空，平台直接把它当成品部署。）

   > 注意：`dist-vercel/` 在 `.gitignore` 里（属于构建产物），普通 `git add` 会静默跳过。
   > 用 GitHub 方式时需要在每次重新生成后**强制加入**：
   > ```bash
   > python tools/build_deploy_vercel.py
   > git add -f dist-vercel && git commit -m "build: 更新 dist-vercel" && git push
   > ```
   > 推上去即触发自动重新部署。嫌麻烦就直接用方式一的 `npx vercel deploy dist-vercel`，根本不用碰 git。
4. **Environment Variables** 加三项：
   ```
   LLM_API_KEY      你的 DeepSeek key
   LLM_BASE_URL     https://api.deepseek.com/v1
   LLM_MODEL        deepseek-chat
   ```
5. 点 **Deploy**

### 上线后验证（关键，避免现场翻车）

- 浏览器打开 `https://你的站点.vercel.app/api/health`
  → 应返回一段 JSON，含 `"mode":"online"`（说明 key 生效、函数挂载成功）。
  如果返回 `"mode":"offline"`，说明环境变量没配或没生效。
- 用手机流量打开主站，问一个跨点位比较题（如「黄洋界保卫战和井冈山会师哪个先发生」），
  若 AI 能跨点位取材作答、且回答带史料出处，说明模型链路通了。

### 不填 key 会怎样

函数会自动降级成「服务端史料直出」——有出处、能拒答，但措辞是史料原文而非模型组织。
比纯静态版好一点（检索在服务端跑），但不如有 key。

> 注意：Vercel 国内访问不稳定，路演主路仍建议用笔记本双击 `v2/index.html`（断网也能演），
> 这个网址版作为「给别人远程看 / 评委扫码」的增强版。

## 上线后建议做三件事

### 1. 生成二维码（路演必备）

你之前那个 `_不用了-二维码/` 目录里写过「扫码打不开」，原因是**当时没有真实网址**，
二维码指向的是 `file:///D:/...` 本地路径，别人手机当然打不开。

现在有了 `https://xxx.edgeone.app`，二维码就能用了：

- 打开 https://cli.im （草料二维码），粘贴网址，生成，下载 PNG
- 打印在 PPT 尾页 / 展板上，评委手机一扫就打开

### 2. 第一次打开时自己走一遍

用手机流量（不要连 WiFi）打开网址，确认：
- 首页能出来，三张点位图能加载
- 点「问 AI」能答、能拒答
- 任务能做、报告能生成

**一定要用手机流量测**——校园网/公司网可能有特殊限制，测出来的结果不代表评委现场的情况。

### 3. 演示时带两条路

路演现场的网络不可信。所以：

- **主路**：手机/笔记本打开网址，走正常流程
- **备路**：笔记本双击 `v2/index.html`（file:// 直接跑，已实测可用）

链接挂了就切备路，别在台上折腾网络。

## 更新内容后怎么重新部署

改完代码后：

```bash
python tools/build_deploy.py
```

会重新生成 `dist/` 和 `dist.zip`（自动剔掉 `PPT素材/`、`_shots/`，只留 3.2MB）。
然后把新的 `dist.zip` 拖到平台上覆盖即可。

如果要更新「带模型」的版本，额外跑：

```bash
python tools/build_deploy_online.py
```

重新生成 `dist-online/` 和 `dist-online.zip`，把新的 `dist-online.zip` 按上面的方式重新上传 / 重新部署即可。

如果要走 **Vercel（带模型）**，改完代码后跑：

```bash
python tools/build_deploy_vercel.py
```

重新生成 `dist-vercel/`，然后：
- 本地命令部署（推荐）：`npx vercel deploy dist-vercel --prod`
- 连 GitHub：`git add -f dist-vercel && git commit -m "build: 更新 dist-vercel" && git push`
  （`dist-vercel/` 在 .gitignore 里，必须 `-f` 强制加入；记得在 Vercel 项目设置里加好那三项环境变量）

## 附：为什么部署包里没有 PPT 素材和截图

`v2/` 有 18.4MB，其中：

- `PPT素材/` 9.8MB —— 做 PPT 用的成品图
- `_shots/` 5.2MB —— 开发时的界面截图

这些是给你自己做材料的，别人打开网站不需要。而且这两个目录里有 28 个中文文件名，
部分托管平台处理中文 URL 会出编码问题。剔掉后：

- 体积 18.4MB → **3.2MB**（省 83%）
- 中文文件名 28 个 → **0 个**
- 首屏加载明显更快，手机流量也扛得住
