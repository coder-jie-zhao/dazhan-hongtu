# 大展红途 · 目录结构说明

## 一句话记住

**根目录 = v1（路演兜底，勿动）｜ `v2/` = 主版本（答辩演示用）｜ 其余目录为共享资产。**

## 第一层：两版运行时（互不干扰）

| 路径 | 版本 | 作用 | 能不能动 |
|---|---|---|---|
| `index.html` / `app.js` / `styles.css` | **v1** | 单点位兜底版首页 | 勿删、勿移 |
| `server.js` / `package.json` | **v1** | 本地服务（8130 端口） | 勿删、勿移 |
| `api/` / `data/` | **v1** | v1 后端与语料 | 勿删、勿移 |
| `html2canvas.min.js` | v1 | v1 首页直接引用 | 勿删 |
| `启动演示.bat` | 共享 | 双击起服务（GBK 编码） | 勿删 |
| `v2/` | **v2** | 主版本：三点位、三档学段、演示导览 | 主开发目录 |

> v1 放在根目录是项目立项时就定下的约定：最坏情况下双击 `index.html` 就能演，
> 断网断电都不依赖任何服务。移动这些文件会破坏这条兜底路线，
> 所以这里只做标注、不做搬迁。

## 第二层：共享资产

| 路径 | 内容 |
|---|---|
| `docs/` | 项目文档、答辩材料、截图、部署说明、本文件 |
| `materials/` | 现场物料（点位牌、扫码卡片、网络实测记录） |
| `tools/` | 构建、出图、验收脚本；`tools/legacy-v1/` 是 v1 出图工具 |
| `PPT素材/` | v1 出图产物（v2 的在 `v2/PPT素材/`） |
| `showcase*.html` / `frame.html` / `_docfig.html` | 出图模板，被 `tools/` 脚本引用 |

## 第三层：部署产物（可重建，不入库）

| 路径 | 用途 | 重建命令 |
|---|---|---|
| `dist/` | EdgeOne 纯静态版（AI 走前端本地检索） | `python tools/build_deploy.py` |
| `dist-online/` · `dist-online.zip` | EdgeOne 带模型版，当前主用 | `python tools/build_deploy_online.py` |
| `dist-vercel/` | Vercel 备用线路；线上站点仍在跑，暂不删 | `python tools/build_deploy_vercel.py` |
| `cloud-functions/` · `edgeone.json` | EdgeOne Git 部署的云函数，必须在仓库根目录 | 不参与构建 |

## 怎么一眼认出版本

- 打开 `index.html`：单一封面图、没有底部导航 → **v1**
- 打开 `v2/index.html`：三个点位卡片 + 底部导航 → **v2**
- 线上 `dist-online/`：v2 带真实模型版
- 引导页出现「小学 / 初中 / 高中」三个按钮 → 是 2026-11-16 之后的新版
